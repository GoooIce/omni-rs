SHARED / SCHEDULER

闲时准入与让出

两个实验分别使用 watch 命令。调度器等待安全的本机闲时条件，再开始实验工作。

准入条件
连续 5 分钟无键鼠输入；连接交流电、低电量模式关闭、温度和内存正常、磁盘至少 5 GiB，且未检测到已知冲突进程。
运行与恢复
约每 500 ms 检查一次；用户返回或协作前台任务请求设备时让出。图表以完整轮次恢复，语音从完整更新检查点续训。
启动方式
手动执行 watch 或 speech-watch；Ctrl-C 后不会自动重启。中文语音的种子准备与核验是独立步骤。

进程扫描和锁不能覆盖所有 GPU 应用，当前没有全系统前台延迟保证。

与完整 RSI 的距离

现在是两个局部实验闭环，尚未复现论文中的联合能力演化。

已经实现

样本核验、真实参数更新、固定开发集门槛、检查点和显式的语音 LoRA 加载。

仍然缺少

图像生成器训练与导出、通用读写底座训练、真实语音候选通过验收，以及充分的跨模态回归。

本机验证记录

  • 图表：三轮候选和原模型均为 20 / 24，暂无晋级或读图提升证据。
  • 语音：真人录音与回放训练 7 次后，底座 CER 为 33.3%、候选为 43.6%，候选未通过。
  • 已知现象：官方中文 TTS 可说中文，普通语音对话的中文语音仍需改善。
