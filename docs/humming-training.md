# 固定前缀的 speech-only 训练原语

`omni_rsi::humming::training` 为 #85 提供一个显式调用的 Rust/Burn 内存训练原语。调用者提供已经自行准入的 16 kHz 单声道伴奏**固定前缀**、任务指令和目标语音码；本接口不读取录音、不从文件加载训练数据，也不启动闲时调度。它不接受文本答案，不添加答案 token，也不计算文本损失。原有音频问答训练保持独立。

`FixedPrefix::new` 要求前缀非空、不超过 320,000 个采样、值有限且在 [-1, 1]；指令非空、不超过 2048 字节且不能包含控制 token 起始符。目标包含 5–200 帧，训练前检查模型要求的码本数、词表边界和全码本结束帧。接口不读取 codec 配置或验证目标码的来源；调用者还须确保码值和码本与实际目标 codec 相符。来源授权、旋律/歌手/派生版本划分和样本本身是否适用于训练也由调用者负责；`FixedPrefix` 的构造成功不证明这些事实。

`Trainer` 持有单独的 `SpeechOptimizer` 和显式目标卷积层。调用 `Trainer::bind(model)` 时，模型所有权进入 `TrainingSession`，训练器的 adapter **立即替换目标层原有 adapter**，并使绑定前的模型推理缓存失效，即使随后没有执行步骤也是如此。绑定失败时，`BindError::into_parts` 返还原训练器及原模型；公开模型接口无法提取并恢复任意已有 adapter，调用者须为绑定选择愿意替换该层的专用模型。

会话持有模型，只允许通过 `model()` 借用不可变引用做推理；每次 `step` 使用同一模型及优化器，不再在计算损失前重装 adapter。它用 `OmniModel::prepare_audio` 编码传入的整个切片，再通过既有 `speech_loss_with_media` 计算语音内容损失和结束帧损失，按 `content + 0.01 * end` 更新 LoRA。返回值标识目标 `omni-rsi.humming.fixed-prefix.speech-only.v1` 并报告两项损失及梯度范数。成功返回时更新后的 LoRA 已安装在会话模型中，先前推理缓存失效；`into_parts()` 可取回训练器和模型。

`model()` 借用的仍是 Autodiff 模型；不可变借用不会隔离训练图，推理得到的 Tensor 和缓存可能与优化器共享该图。可以做前向推理并读回输出；如果还要复用训练器，不要对这些输出调用 `backward()` 或进行外部反向传播。合成 CPU 测试中，主动反向后下一步会因缺少 LoRA 梯度报错，成功回滚会保留参数值、使旧缓存失效，之后可重试；不能把此行为当作支持外部反向传播或保证其他后端有相同结果。`into_parts()` 不会把返回模型转为非 Autodiff 模型，也不会隔离其与训练器共享的图。

开始前取消、帧校验失败、音频准备或损失计算失败不会替换会话模型的 adapter，既有缓存仍可用。更新前会保留临时优化器副本；优化器更新报错、更新后观察到取消，或安装更新后的 adapter 失败时，会恢复优化器并重装回退 adapter。**回滚会使旧推理缓存失效**，即使取消发生在新 adapter 尚未安装之前也是如此：仅恢复优化器的数值不能恢复与模型现有 adapter 的 autodiff 图连接。合成 CPU 对照还发现，反向后零梯度或非有限梯度虽不改变参数数值，不重建图也会导致下一次训练缺失梯度；这些更新错误需要相同的事务回滚。回滚安装若失败，会话标记为不可用，拒绝模型访问、续训和取回模型，销毁会话时丢弃模型；调用者必须丢弃从该模型取得的缓存。若取消恰在最后一次检查之后发生，已提交的步骤不会被追溯撤销，单次模型前向/反向内部也不保证立即停止。目前未对更新过程中的取消进行确定性定点测试。

该接口只证明计算接收了调用者提供的切片。它不接受或推断采样时间戳，不能证明每个目标帧只依赖实时可见的伴奏；逐帧对齐、固定延迟与实时因果跟唱需要后续更强的时间界面。训练器没有检查点、恢复、候选发布或晋级接口；`weights()` 只供检查当前内存参数，不能当作经过身份绑定的检查点。生产接线前仍需设计绑定模型、数据、任务版本、层、优化器状态及采样规则的独立协议和失败关闭的恢复/门控路径，不能把此目标写入 #79 或文本答案训练状态。

合成测试把仓库已有的小型文本、音频编码器、语音深度解码器和 codec 夹具组合并裁剪到一致的文本宽度；codec 仅为构造模型而加载，测试不运行 codec，也不声称合成语音码来自该 codec。两种合成正弦前缀在同初值和随机种子下产生不同的语音损失及梯度；相同切片配不同未传入的尾部则产生相同结果。另一组 24 层合成夹具执行原有音频问答训练，单独验证原文本与语音目标仍工作。这些只是计算接线与边界测试，不能证明真人哼唱、自然 codec 保真、数据许可、听审、跟唱能力改善或真实闲时调度质量。

离线测试要求当前 Cargo 使用的可信 home 已有锁文件所需的依赖缓存；新克隆或新建的空 Cargo home 不会自带缓存，`--offline` 不会下载依赖。以下沿用调用者现有的 Cargo home，不自动修改其设置；构建产物使用本检出的私有 target：

```sh
CARGO_TARGET_DIR="$PWD/artifacts/humming-training-target" \
CARGO_BUILD_JOBS=1 CARGO_NET_OFFLINE=true \
  cargo test --offline --locked --manifest-path crates/omni-rsi/Cargo.toml \
  --no-default-features --features cpu --test humming_training -- --test-threads=1
```
