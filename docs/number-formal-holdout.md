# 数字听答正式保留流程：尚未开放的接线

本切片提供一次性报告的受控编排与合成测试，**没有可签发的生产资格，也没有正式保留验收入口**。`QualifiedSession` 的字段私有、不可反序列化或克隆，生产构建没有构造器；执行器在生产中不可用。传入空资格直接返回 `InsufficientEvidence`，不检查账本、报告或私有路径。测试专用资格和模拟执行器只在测试编译中存在，模拟报告始终标记为 `synthetic_test_only`、`insufficient_evidence`、`candidate_eligible: false`，不证明模型改善，不启用或发布候选。

## 占用与报告

内部编排先核对公开承诺及其不透明凭据，验证绑定路径，再检查报告目标是否已经存在；已有目标会在记账前拒绝，不消耗保留集。路径检查读取私有**目录本身及其祖先的元数据**（类型、权限、设备号和 inode），不打开或读取盐、私有清单、答案或媒体。它比较现有目录的实际设备号和 inode，拒绝保留目录、账本和报告互相嵌套；祖先和私有目录末级均不得是符号链接。相对路径、`.` 和 `..` 被拒绝。大小写或 Unicode 规范化后指向已有目录的别名按目录身份检测，而不是只比较字符串。

现有目录身份并不等于来源或权限的真实性。当账本和报告都尚不存在、且父目录实际相同时，不能用 inode 比较它们未来的名字；该情况下末级名称目前只支持 ASCII 和基本汉字 `U+4E00`–`U+9FFF`，按保守的 ASCII 大小写折叠检查是否重名。其他 Unicode 末级名称会在预检拒绝；Unicode 祖先、私有目录名以及不同父目录下的末级名称不受此字符集限制。含符号链接的系统路径也需由操作者提供真实、无链接的绝对路径。这个限制不表示所有合法文件系统路径均已支持。

预检通过后，盲保留模块先以共享账本同步记录占用，返回只能消费一次的内部占用对象；之后重查私有和报告祖先身份，创建新的 0700 报告目录，再打开并验证秘密盐、清单和媒体。报告以私有临时文件写入、同步后原子无覆盖发布，并同步报告目录；报告可能包含答案和逐题输出，应按私有资料保管。报告不会自动发布到任何服务。

占用操作报错时，持久化可能已经发生，因此统一视为 `ConsumedOrUncertain`。预检与目录创建之间若发生竞争，或记账后的同步、取消、崩溃、媒体校验、推理和报告发布失败，也可能已经消耗；不得自动撤销或换报告目录重试。正式编排在打开私有文件前及读取、计算媒体哈希时逐块检查取消；正在执行的单次系统调用不能被该检查抢占。目录身份检查不是防恶意同账号篡改或并发替换的安全边界。账本仍只约束使用同一目录且遵守协议的进程，有权者可以更换或删除账本、复制数据或伪造来源。

## 合成复算与剩余工作

测试执行使用临时合成 WAV 和仅测试可用的内部执行器：基于实际打开的每题音频，按确定性的不同答案一对一交换及等长静音生成两臂、三个条件，记录输入 PCM/文件身份、交换来源、原始文本、结束及规则答案并重新计分。成对统计调用现有独立计算；结束词须属于会话给出的集合。音频解码和输出大小有上限；无解交换、无效 WAV、非法终止词、中断或报告写入失败都不能重试。测试中的停止词与输出均为合成值，不是 v3 冻结策略或真实模型执行的证明。

正式资格仍须接入受控 Rust/Burn 实际开发推理与不可伪造的同会话执行记录，重新绑定并核验规则、实际训练/开发数据和来源分组、公开保留承诺、底座、候选及训练来源、codec、评估器、R2T2、实现、完整生成参数和逐题文本/语音结果，并按冻结阈值重算。保留集的交换算法、评分实现与全部参数也须预先注册并绑定；当前新模块的代码哈希和测试报告不构成这种绑定。

来源许可、真人独立输入参考、生成语音的人类听审和已注册的中文、英文、其他 Omni、朗读、对话回归都须经可信流程实际核验；声明和哈希只能绑定记录，不能证明其真实性。盲格式 v2 不含秘密目标语音，不能据此声称该语音目标已独立隔离或验收。正式保留执行还缺少真实模型、生成语音、R2T2 与人工审核的受控路径、按实际冻结 v3 停止词和参数的完整复核，以及最终保留报告。以上任一缺失时继续证据不足，不得发放资格或读取真实保留内容。本轮没有打开真实保留集，也没有运行模型、麦克风或 GPU。
