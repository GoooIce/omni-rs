# 数字听答正式保留流程：尚未开放的接线

本切片提供一次性报告的受控编排与合成测试，**没有可签发的生产资格，也没有正式保留验收入口**。`QualifiedSession` 的字段私有、不可反序列化或克隆，生产构建没有构造器；执行器在生产中不可用。传入空资格直接返回 `InsufficientEvidence`，不检查账本、报告或私有路径。测试专用资格和模拟执行器只在测试编译中存在，模拟报告始终标记为 `synthetic_test_only`、`insufficient_evidence`、`candidate_eligible: false`，不证明模型改善，不启用或发布候选。

## 占用与报告

内部编排先核对公开承诺及其不透明凭据、非空停止词策略和绑定路径，再检查报告目标是否已经存在；失败发生在记账前，不消耗保留集。`run_holdout_once` 接受 `&mut Option<QualifiedSession>`：无副作用的预检拒绝保留原有、不可克隆的资格；实际尝试记账前取走资格，记账结果不确定或之后失败均不归还。路径检查读取私有**目录本身及其祖先的元数据**（类型、权限、设备号和 inode），并检查私有目录与报告父目录的 ACL，不打开或读取盐、私有清单、答案或媒体。它比较现有目录的实际设备号和 inode，拒绝保留目录、账本和报告互相嵌套；祖先和私有目录末级均不得是符号链接。相对路径、`.` 和 `..` 被拒绝。大小写或 Unicode 规范化后指向已有目录的别名按目录身份检测，而不是只比较字符串。

现有目录身份并不等于来源或权限的真实性。当账本和报告都尚不存在、且父目录实际相同时，不能用 inode 比较它们未来的名字；该情况下末级名称目前只支持 ASCII 和基本汉字 `U+4E00`–`U+9FFF`，按保守的 ASCII 大小写折叠检查是否重名。其他 Unicode 末级名称会在预检拒绝；Unicode 祖先、私有目录名以及不同父目录下的末级名称不受此字符集限制。含符号链接的系统路径也需由操作者提供真实、无链接的绝对路径。这个限制不表示所有合法文件系统路径均已支持。

预检通过后，盲保留模块先以共享账本同步记录占用，返回只能消费一次的内部占用对象；之后重查私有和报告祖先身份，创建新的 0700 报告目录，再打开并验证秘密盐、清单和媒体。macOS 上从已打开的目录或文件描述符查询扩展 ACL，拒绝任何 ACL 条目或无法核验的结果；私有文件在读取前、报告临时文件和审计文件在写入前也分别检查。私有目录、报告及审计文件须由当前有效用户拥有；新报告和审计文件须可由所有者读写且对组和其他用户无权限。封存私有资料时同样在写入敏感内容前检查父目录、新目录及各文件。此策略保守地拒绝无害的 ACL，不能防同账号并发修改、文件系统虚报或私有材料在别处已有副本和硬链接。报告以私有临时文件写入、同步后原子无覆盖发布，并同步报告目录；报告可能包含答案和逐题输出，应按私有资料保管。报告不会自动发布到任何服务。

当前只在 macOS 实现并实测上述 ACL 核验。Linux、Windows 及其他平台的 `CustodianSeal::persist_private` 和 `open_once` 在创建私有文件或占用账本之前失败关闭；正式编排也不能在这些平台取得可用的私有 ACL 验证。这改变了以往仅依赖 Unix 权限位的盲集私有读写 API 可用范围。公开元数据格式、公开承诺和独立账本计算仍可使用；不支持平台不能因权限位为 0700/0600 而被称为已验证。Linux 的条件编译和模拟不等于 Linux 实机或文件系统验证。

**并发替换边界：**目录描述符只验证当时打开的目录；`Journal::create`、`persist_private` 和 `open_reserved` 后续仍通过 `directory.join(...)` 按路径打开子文件，没有用固定目录描述符和 `openat` 绑定父目录。末级 `O_NOFOLLOW` 只限制末级链接，不能阻止父目录或祖先在检查后被重命名、替换或重指。各实际打开文件的 ACL 会另行核验，报告和日志文件还核验所有者及 0600，但这些检查不能证明其父目录就是先前核验的目录。此实现要求有权替换这些目录或写入其父目录的主体遵守本地协作约定；该限制不限于同账号。静态链接拒绝、报告目录竞争及继承 ACL 的合成测试不证明检查后的目录替换安全。是否以及如何使用目录描述符相对操作消除该窗口，留待独立审查；若占用已发生，错误仍不能撤销账本记录。

报告目录创建后、读取私有文件前，新建且不覆盖 `raw-observations.jsonl`；目录项和日志头先同步。每次推理前同步记录输入身份，每次返回后在判断停止词或取消之前同步原始文本及结束原因；失败事件尽力另行写入。日志头固定标记 `incomplete_attempt`、`not_a_success_report` 和 `candidate_eligible: false`，完整报告记录发布时日志文件的 SHA-256。单条文本超过 4096 字节时只保存合法 UTF-8 前缀、原长度和 `text_complete: false`，随后拒绝该尝试；日志总量上限为 128 MiB。写入、同步或发布失败不会撤销占用，也可能无法保存最后一条记录：只可审计已经成功同步的完整行，断尾或尚未返回的推理结果不能视为完整证据。若进程在建立报告目录或日志前退出，则可能只有账本记录；存储或权限失败不能保证失败事件本身写入成功。报告发布后若目录同步失败，后续失败记录会改变日志摘要，必须按失败处理。当前测试执行器在返回错误时不提供未返回的生成片段；未来真实执行器必须先接入受控的流式原始观察及中断持久化，不能假定本测试接口已经保存这些片段。

占用操作报错时，持久化可能已经发生，因此统一视为 `ConsumedOrUncertain`。预检与目录创建之间若发生竞争，或记账后的同步、取消、崩溃、媒体校验、推理和报告发布失败，也可能已经消耗；不得自动撤销或换报告目录重试。正式编排在打开私有文件前及读取、计算媒体哈希时逐块检查取消；正在执行的单次系统调用不能被该检查抢占。目录身份检查不是防恶意同账号篡改或并发替换的安全边界。账本仍只约束使用同一目录且遵守协议的进程，有权者可以更换或删除账本、复制数据或伪造来源。

## 合成复算与剩余工作

测试执行使用临时合成 WAV 和仅测试可用的内部执行器：基于实际打开的每题音频，按确定性的不同答案一对一交换及等长静音生成两臂、三个条件，记录输入 PCM/文件身份、交换来源、原始文本、结束及规则答案并重新计分。全零原音及重复的规范 PCM 在占用后拒绝，避免静音与原音相同或重复样本冒充独立统计；低幅非零音频不按峰值阈值排除。成对统计调用现有计算，区间的独立性仍以未经核验的来源、家庭、说话人及会话分组声明互异为条件，不能证明真人或来源独立。结束词须属于会话给出的集合。音频解码和输出大小有上限；无解交换、无效 WAV、非法终止词、中断或报告写入失败都不能重试。

会话在取得测试资格时冻结比较身份，预检会用实际停止集合及当前实现重新计算并核对；报告和原始日志均记录排序去重后的停止 token、停止策略 SHA-256、实现 SHA-256、协议 SHA-256 和组合后的 `formal_comparison_sha256`。停止策略摘要以 `omni-rsi/formal-stop-policy/v1\0`、大端 u64 token 数及各大端 u32 token 计算；实现摘要按固定顺序以域标记、长度前缀名称和源码字节计算，覆盖本模块的编排、身份、日志、评分、盲读、开发 PCM 身份、账本、统计、数字评分、WAV 解码和 ACL 源码。它不覆盖全部依赖、编译器、模型或实际执行二进制。比较摘要以 `omni-rsi/formal-comparison/v1\0` 和长度前缀的协议、停止策略及实现摘要的 ASCII 十六进制值计算。这使不同实际策略或所列源码对应不同身份，并可复算报告，但不能证明所声称协议确由可信注册产生，也不把停止策略写入旧账本协议字段。测试中的停止词与输出均为合成值，不是 v3 冻结策略或真实模型执行的证明。

正式合成评分、开发集注册和 v3 比较共用规范 PCM 摘要逻辑；正负零视为同一采样值。为此修改的开发集注册及 v3 评测源码会改变绑定这些源码的 v3 训练、注册和评测身份：旧状态与冻结记录保留原件，不自动迁移或覆盖，需要按当前实现重新核验。该变更不修改 #79 的独立检查点实现摘要。

正式资格仍须接入受控 Rust/Burn 实际开发推理与不可伪造的同会话执行记录，重新绑定并核验规则、实际训练/开发数据和来源分组、公开保留承诺、底座、候选及训练来源、codec、评估器、R2T2、实现、完整生成参数和逐题文本/语音结果，并按冻结阈值重算。保留集的交换算法、评分实现与全部参数也须预先注册并绑定；当前新模块的代码哈希和测试报告不构成这种绑定。

来源许可、真人独立输入参考、生成语音的人类听审和已注册的中文、英文、其他 Omni、朗读、对话回归都须经可信流程实际核验；声明和哈希只能绑定记录，不能证明其真实性。盲格式 v2 不含秘密目标语音，不能据此声称该语音目标已独立隔离或验收。正式保留执行还缺少真实模型、生成语音、R2T2 与人工审核的受控路径、按实际冻结 v3 停止词和参数的完整复核，以及最终保留报告。以上任一缺失时继续证据不足，不得发放资格或读取真实保留内容。本轮没有打开真实保留集，也没有运行模型、麦克风或 GPU。
