# #80 中文听音数字问答：公开真人语料线索

核查日期：2026-11-10。最初调研读取发布方说明、原论文和许可正文；随后补充了 AISHELL-3 训练文本及说话人元数据的探索性统计，没有下载该语料音频或建立其保留集，也未使用云识别。项目另行选取了四条 OMPAL 录音，仅用于非盲探索，不能作为独立验收数据。这里的“候选”仅指值得继续核查，不代表已确认使用条件、足够的合格数字样本或独立验收。

## 结论与优先级

**尚无已证实同时满足全部条件的公开 0–99 独立数词语料。** AISHELL-3 的训练文本粗筛仅找到少量完整数词候选；Common Voice 7.0 单词专项更贴近独立数字，但中文目标样本覆盖尚未证实。所有拟议使用都须先通过说话人、来源文本和派生家族的隔离检查；这次没有进行音频级核验。

### 有条件的开发候选：AISHELL-3

- [原论文](https://www.isca-archive.org/interspeech_2021/shi21c_interspeech.pdf)和[发布方数据卡](https://huggingface.co/datasets/AISHELL/AISHELL-3/blob/main/README.md)描述约 85 小时、218 名母语说话人的真人朗读，带说话人相关信息；字符及发音标签是录音后人工转写，卡片称经专业校验。虽常用于训练 TTS，**原录音是人声**。论文明确说脚本题材包括数字串。
- 论文和发布方数据卡标示 [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0.txt)；但[发布方官网](https://www.aishelltech.com/aishell_3)的可检索文本同时列出 Apache-2.0 和 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en)，未明确两者各自适用对象。**不能仅据数据卡断言全部发布渠道和衍生用途均无非商业／相同方式共享限制；应先澄清具体版本和许可对应关系。** 论文报告说话人分布偏女性、年轻及北方口音，且为安静环境下的中性朗读，不等于自然对话。
- **训练文本粗筛：**在发布方仓库固定版本 `f20d5db4a31fe779ef07bb1af4ea92da5c786622`，本地读取了 [train/content.txt](https://huggingface.co/datasets/AISHELL/AISHELL-3/blob/f20d5db4a31fe779ef07bb1af4ea92da5c786622/train/content.txt) 和 [spk-info.txt](https://huggingface.co/datasets/AISHELL/AISHELL-3/blob/f20d5db4a31fe779ef07bb1af4ea92da5c786622/spk-info.txt)。前者 SHA-256 为 `ed70f67d5558124ee22e609260177eaf20aa63391dd9df8df0a7e22b9213aca0`，后者为 `86148f95beab318ad9d08bf945b1d56ffba8c97b09137ae784cc62b0cd6539ef`。63,262 条训练文本的文件名前缀均匹配 218 条说话人元数据中的 ID；这不证明原始录音、会话或真实身份均已核实。
- 对字符／拼音交替字段使用有限的中文 0–99 书写形式筛选，得到 **5 条整句数词文本候选，来自 3 个说话人 ID**；该规则不是穷尽性的语言解析，也不把多位数字串解释成整数。另有 12,706 个句子包含一个连续数词字符片段、涉及 148 个 ID，但“一个”的“一”、日期和上下文都可能产生误匹配，不能把该数值当成有效数字题数。相关脚本和原始汇总保存在本机 `artifacts/audio-rsi-p0/aishell3-metadata/`，不把逐题标签纳入正式保留集。
- **尚不确定：**上述统计未听取任何录音，无法确认实际读法、完整性、授权和来源独立性；5 条候选也不足以满足 30 个独立案例的门槛。若后续使用句内数字或数字串，必须另做边界、读法及人工听审，作为有语境偏差的独立分组，而非宣称等同整句数词。

### 不确定，但值得核查：Common Voice 单词专项与中文朗读

- [Common Voice 7.0 Single Word Target Segment 官方卡](https://mozilladatacollective.com/datasets/cmkzhp64p00wlno07elrmt20y)列出 0–9、中文大陆、香港和台湾等 34 个语种／地区，许可标为 [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en)，用途包括训练和评估 ASR。[Mozilla 的采集说明](https://discourse.mozilla.org/t/help-create-common-voices-first-target-segment/59587)说明是志愿者读出单词并由其他贡献者听审；[Common Voice 原论文](https://aclanthology.org/2020.lrec-1.520.pdf)说明常规数据的匿名 `client_id` 和人工投票流程。
- 专项卡**没有公布中文各数字的实际条数、有效听审数、说话人数，亦未逐项确认该包保留的 ID 字段**；84 小时有效语音是所有语种合计，不能算作中文数字。其目标为 0–9，并不能满足 10–99。后续只有确认中文确实有多个可靠匿名 ID、目标数字及人工通过的片段后才可入选；中文地区标签不保证每名说话人都是普通话母语者，香港／台湾分项需核实实际语种并分组。
- [Common Voice 27.0 中国大陆中文官方卡](https://mozilladatacollective.com/datasets/cmu5lcunh00qimh078sdd5so8)是另一个宽许可真人朗读候选：整套数据列出 7,601 名说话人、240.11 小时已验证语音，字段包括匿名 `client_id` 和听审投票。这是**全体中文句子**的统计，不是数字样本统计；数字数量、完整单独数词和 0–99 覆盖均未知。以句内数字制题会引入上下文和朗读偏差。
- Mozilla 两张卡均标 CC0，同时写明禁止**尝试确定说话人身份**及**重新托管或再分享数据集**。[官方 FAQ](https://community.mozilladatacollective.com/faq-why-cant-i-re-host-or-share-common-voice-datasets-that-i-download-from-mdc/)说明 CC0 用于计算，禁止镜像是平台条款。用匿名 `client_id` 按贡献者分组在目的上不同于去匿名识别；但专项包是否有这一字段、如何分组符合适用条款仍需核实。`client_id` 是账户／贡献者标识，不保证与实际个体一一对应，因此 ID 不重叠不自动证明真人不重叠，也不能通过去匿名来补救。本地用途参考数据卡；对外分享数据或衍生材料前需厘清发布方限制，不能只凭 CC0 标签假定无额外条件。
- **获取方式及附加协议：**[Mozilla 官方说明](https://community.mozilladatacollective.com/were-changing-access-to-older-versions-of-common-voice-datasets/)称下载者需使用已验证邮箱并接受不再分享条款；历史版本需邮件申请、说明版本和用途，并确认仅研究和不再分享。[官方 FAQ](https://community.mozilladatacollective.com/faq-how-can-i-contribute-to-mozilla-data-collective/)建议创建账号以访问数据。该单词专项虽然名为 7.0，但目前目录列为单独发布项；**是否适用历史版本的邮件申请、是否必须注册账号、点击下载时是否还有其他专项协议，本次未登录或点击下载，不能确认。**

### 有用但有明显限制

- **OMPAL：**[作者仓库及许可](https://github.com/phantomhsieh/OMPAL-corpus)为 CC BY 4.0，有 3 名母语 ID、46 名法语 L1 学习者；[原论文](https://www.isca-archive.org/interspeech_2025/hsieh25b_interspeech.pdf)以初中级学习者对话朗读为主，不能当作多母语者、独立数字的代表。论文称每条由四位专家中的三位评估；它的发音评分在特定遗忘漏读情况下可标为正确，因此词级高分不等于实际读出了目标数字。若未来作为非母语扩展，应另行盲听核实真实内容并单独报告；数字覆盖未知。[CC BY 4.0 正文](https://creativecommons.org/licenses/by/4.0/legalcode.en)。
- **ManDi：**[原论文](https://aclanthology.org/2022.lrec-1.213.pdf)描述 36 位不同官话方言背景说话人，包含普通话及方言朗读、可区分说话人的文件命名，论文声明 CC BY-NC 3.0。其文本可能缺失或与录音不符，词／音素边界主要靠强制对齐，只有部分人工修正；不能把对齐边界当独立数字真值。论文未证实目标数字覆盖；[作者指向的 OSF 页面](https://osf.io/fgv4w/)本次返回 403，当前可获取性及版本许可未能复核。[CC BY-NC 3.0 正文](https://creativecommons.org/licenses/by-nc/3.0/legalcode.en)允许规定范围内的非商业改编，须署名并标明修改；仅适合实际用途符合非商业条件的探索。
- **FLEURS：**[作者论文](https://arxiv.org/abs/2205.12446)称由母语者朗读、其他工作人员核对录音与文本；[Google 数据卡](https://huggingface.co/datasets/google/fleurs/blob/main/README.md)标 CC BY 4.0。它是百科句子而非独立数字集；卡片列出的 `id` 是音频样本 ID，未见可用于逐说话人分组的 ID。数字覆盖及严格说话人隔离未确认，不作为本任务的主来源。

## 当前拒绝或暂不采用

- **AISHELL-1：**[发布方原论文](https://arxiv.org/abs/1709.05522)和[原始规格书](https://catalog.ldc.upenn.edu/docs/LDC2018S14/AISHELL-1_specification.pdf)表明公开子集是财经、科技、体育、娱乐和新闻朗读，原始大库的数字串类别不在该公开子集中。真人和人工转写不能证明数字样本存在。项目已有 AISHELL 真人保留材料，不能因公开许可就把该源自动加入训练；在受控隔离机制证明无说话人、录音和派生家族冲突之前暂停。
- **THCHS-30 对齐标注：**[原论文](https://arxiv.org/abs/1512.01882)描述的是新闻句子朗读；现有对齐边界本身不是独立人工听审的孤立数字真值。本任务不采用对齐片段冒充已验证数字。
- **SHALCAS22A：**按本次任务给定的 CC BY-NC-ND 4.0 信息，当前要求可复用的衍生数据，故先排除。其[许可正文](https://creativecommons.org/licenses/by-nc-nd/4.0/legalcode.en)限制商业用途和分享改编材料；这不等于断言所有私下处理均被禁止。未找到可独立核实的新发布方许可文本，待额外授权及条件明确后再议。
- **MagicHub 的特定 Proprietary 候选：**按任务给定信息排除，不能拿镜像的宽松标签代替该数据本身的授权。MagicHub 还发布其他数据，不能据此断言平台上全部数据均为 Proprietary；[平台目录](https://magichub.com/datasets/)本身区分不同类别。
- **SpokeN-100：**[作者发布记录](https://zenodo.org/records/10810044)明确整个数据集为人工生成语音；尽管含中文 0–99，不能算真人迁移验证。
- **23 人中文数字论文数据：**[原论文](https://wcse.org/WCSE_2021_Spring/002.pdf)描述 23 人各读 0–9，但未在论文中找到可核验的公开下载、数据许可或独立文本听审说明；不能据此声称可获取或可用于本项目。

## 后续选取与防泄露策略

1. **先隔离，再选样。** 固定数据版本、许可与来源；仅对获准的开发／训练候选范围操作。由独立受控流程按匿名说话人、会话、原始录音、文本来源及裁剪／变速等派生家族判定跨集合冲突；只输出通过／冲突信息，不向训练或选型流程暴露保留集内容。无法证明隔离时暂停使用。原始精确哈希不足以识别变速或裁剪后的同源片段，也不能证明说话人独立。
2. **真值来自听审。** 优先整条只包含一个 0–99 数词的原始真人录音；独立听审者先不看提示文本写下实际听到的数字，再与原人工记录比较，无法判断、漏读、重复、夹杂其他数字或边界不清的样本剔除或标为不可判。若使用句内剪裁，先人工复核边界与上下文，并单列报告；不把强制对齐或 R2T2 转写当作独立真值。
3. **文本不携带答案。** 指令只描述统一规则，数字与规则计算出的答案保存在模型不可见的标注侧；输入只给同一指令与目标音频。文件名、路径、样本顺序、说话人 ID、数据源、时长或静音处理方式不应可预测答案。按数字、说话人、设备和文本上下文检查可用分布与偏差；无法均衡时如实报告，不凭总时长推断样本量。
4. **固定任务与负对照。** 在本地用规则计算答案，预先定义数词归一化、同义读法和 0–99 输入边界的处理；基座和候选使用相同输入与解码。配对交换音频时答案应随音频改变，并检查静音、无关音频和相同前缀尚不可区分时的等待／弃答。答案判定由独立参考执行，不能把模型对自己输出的识别结果当真值。
5. **分别声明泛化范围。** 严格验收按说话人、会话、原始文本及派生家族隔离。孤立数字词汇很小：若某项实验在训练和开发中重复同一个数词，它只能衡量已见词汇上的新说话人泛化，须明确标注这种文本重合，不能冒充未见文本家族的验收；若要检验未见数字构词，还须另设互不重叠的数字／文本家族方案。
6. **本地链路与记录。** 后续训练／推理沿用 Rust/Burn；Breeze 产生的回答或增强音频明确标为合成，单独统计，不能算真人输入。R2T2 可作本机辅助检查，不能代替人工参考或数学规则答案。记录来源、许可版本、说话人匿名 ID、会话、文本与派生家族、处理方式和模型版本。

## 检索限制

本机 `jev --help` 返回 `command not found`，工具目录中也没有 Jev 搜索工具；因此无法执行 `jev-search` 的排序与充分性决策，本记录未声称使用过 Jev。按照任务要求改为自行核对一手资料；仅对明确读到的内容下结论。ManDi 的 OSF 页面返回 403，其数据版本和可用性仍未验证。
