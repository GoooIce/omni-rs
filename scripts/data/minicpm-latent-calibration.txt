下面这段代码把一组成绩分成及格与不及格，并保持原来的先后次序。它不调用现成的排序，而是用两个列表各自追加。空列表要先判断，否则平均值会除以零。函数最后返回三样东西：及格名单、不及格名单，以及全体平均分。调用者如果只想要平均分，可以用下划线把前两个丢掉。

def split_scores(scores):
    passed, failed = [], []
    for name, score in scores:
        (passed if score >= 60 else failed).append((name, score))
    total = sum(score for _, score in scores)
    average = total / len(scores) if scores else 0.0
    return passed, failed, average
